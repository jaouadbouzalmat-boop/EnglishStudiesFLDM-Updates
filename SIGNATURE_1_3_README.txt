ENGLISH STUDIES FLDM — VERSION 1.3

Le projet conserve la configuration de signature release de l'application.

Génération :
1. Extrait complètement le dossier du projet.
2. Double-clique sur GENERER_APK_1_3_SIGNE.bat.
3. Le script détecte Java et le SDK Android.
4. Il génère la variante release.
5. Il vérifie la signature avec apksigner.
6. Il copie l'APK vérifié sous le nom EnglishStudiesFLDM_v1.3.apk.

Ne publie jamais le keystore ni le fichier keystore.properties.
